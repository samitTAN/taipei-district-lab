# 可選法規初檢

核對日期：2026-10-24；規則版本：tw-taipei-council-20261024。只適用既有臺北市區域議員選區的公民草案，不處理立委選區、縣市改制例外或原住民身分選區重劃。

在自行重劃模式勾選「啟用法規檢查」，不會限制繪圖或自動改變方案。關閉後仍保留一般完整性／幾何提示。前端靜態版與 FastAPI 以同一 data/legal-rules.json 記錄法條、說明與版本。

## 結果意義

- 已檢查：該有限項目完成，不能推導整體合法。
- 有問題：未分配里、空選區等草案問題，或指定變更案的日期晚於計算期限。草案問題不等同主管機關已認定違法。
- 待審議：行政區分割、幾何未連通或正式程序等須人工／主管機關判斷的項目。
- 缺資料：法定月份人口、原住民人口扣除、各區應選名額及適用屆次等不足。
- 未選用：沒有勾選變更公告期限情境，未執行該項日期檢查。

整體結論僅為 issues_found（發現草案或期限問題）或 requires_review（仍待審議），永不回傳「合法／全部符合法規」。API 的 legal_compliance_assessed 固定為 false。

## 法源與實作界線

[選罷法第36條](https://law.moj.gov.tw/LawClass/LawAll.aspx?pcode=D0020010)規範地方選區範圍與原住民制度。工具只包含台北市 456 里，不能驗證未載入的市外範圍；完整性是提案前置檢查，不把里不可拆分當成獨立法律命令。

[選罷法第37條](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=D0020010&flno=37)要求考慮行政區域、人口、地理、交通、歷史及名額，並規範中選會劃分公告。工具列出被分配至多個選區的行政區，供說明與審議；不將行政區分割直接當成違法。共邊連通只是地理參考，不能替代交通與歷史判斷，也不作為獨立硬性法律門檻。

勾選「另以選區變更案檢查公告期限」後，使用者可選 2026 或 2030 規劃情境，任期屆滿日設為該年 12-25，以前一年 12-25 為日期比較基準。等於期限當日不標為逾期，晚於才提示問題。日期由使用者指定；工具不推定草案是否已構成正式變更，也不查證公告、機關權限、例外或2030正式選務時程。未勾選時不根據日曆或與第14屆基準的差異自動認定逾期。

[選罷法第38條第2項](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=D0020010&flno=38)的人口基準，以及[地方制度法第33條](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=A0040003&flno=33)、[地方立法機關組織準則第5條](https://laws.gov.taipei/Law/LawSearch/LawArticleContent/FL001122)的名額與保障制度，需額外資料及目標屆次才能適用。目前未接入法定月份戶籍人口或各選區應選名額，因此不計算人口平衡或保障席次。2022 選舉人數不可當成戶籍人口。2030 年就職起的性別保障新制，亦不可直接套用到2022歷史結果或2026。

未使用立委選區的 ±15% 人口差距作為議員合法門檻；沒有設定固定六個選區、完整行政區或共邊連通為法律強制條件。

## API

GET /api/legal/rules 回傳版本、法條來源與項目。

POST /api/legal/check 接受：

```json
{
  "plan": "以完整 v1 或 v2 方案物件取代此字串",
  "check_deadline": true,
  "election_year": 2030,
  "publication_date": "2026-10-24"
}
```

plan 必須為實際方案物件；上述字串只是欄位位置說明。check_deadline 預設 false；true 時必須有有效 ISO 日期。年份只支援整數 2026、2030。不接受不同圖資版本或缺少里代碼的 v2 方案。

回應 items 含狀態與法條，facts 含未分配數、空選區、分割行政區、未連通區及日期比較資料。輸入錯誤回傳 422，圖資不可用回傳 503。此 API 不儲存使用者方案。


## 立委模式

規則見data/legal-legislator.json。依選罷法第35、37條及第11屆範圍，固定台北8區各1席；行政區分割不自動判違法。人口均衡缺法定基準戶籍人口及原住民人口扣除資料，不以選舉人數代替。

立委每十年檢討及第37條之人口基準、送立法院同意等程序不同，本版將期限列待審議，不套用議員2026/2030日期情境。沒有整體合法認定。
