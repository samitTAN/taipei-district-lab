目前使用臺北市政府民政局「臺北市里界圖」，不再使用 twgeojson 歷史區界。包含 456 個里、12 個行政區，保留原始 CPTVID 作為字串識別碼。里名可能重複，介面顯示「區＋里」。

- 官方資料：https://data.taipei/dataset/detail?id=6b17b31d-4e16-495e-95b1-9fd1f47c80d8
- 授權宣告：https://data.gov.tw/dataset/121163
- 授權：政府資料開放授權條款第 1 版；需保留出處及加工說明，不適用程式碼 MIT。
- 下載資源更新日期：2026-09-21 14:26:43（台北時間）。
- 平台收錄期間迄日：2025-06-17。檔案更新日不能當作每條邊界的生效日；不宣稱其與 2026-10-24 每條現行法定邊界已逐筆比對。
- 原始 ZIP、SHA-256、下載網址、座標與日期見 data/villages-source.json。

## 處理流程

`python scripts/prepare_villages.py --source /path/to/official.zip` 可重製；需要 `pip install -e '.[geo]'`。不帶 --source 會下載官方資源。若雜湊不同，程式會拒絕處理，需先查核新版內容。

1. 讀取 ZIP 內 SHP／DBF／PRJ，依 UTF-8 解析屬性。
2. 由 PRJ 識別為 EPSG:3826（TWD97／121 分帶），以 pyproj 轉為 EPSG:4326。
3. 驗證 456 個唯一里代碼、各區數量、非空且有效的 Polygon／MultiPolygon；不靜默修補原圖形。
4. 在原始公尺座標上建立共邊關係：邊界交集長度須大於 0.1 公尺，點接觸不算鄰接。不考慮橋梁交通或行政例外。
5. 保留全部里界座標，不套用簡化；附加里內代表點與相鄰里代碼。
6. 產生 data/taipei-villages.json；融合各區下的里，產生相容 v1 API 的 data/taipei-districts.json。

衍生資料已納入 Git，正常執行不需要 GIS 套件或重新下載。`npm run data:prepare` 只核對資料筆數、版本與鄰接參照，並建立舊測試／靜態預覽所需的 data/taipei.json 副本。上游更新時需同步更新 dataset_version，舊里級方案版本不符會拒絕匯入，避免代碼換義。
