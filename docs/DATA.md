## 歷史圖資可重現流程

機器可讀的網址、上游 commit、SHA-256、擷取條件與筆數在 `data/source.json`。`npm run data:prepare` 先核對原始檔案雜湊，再擷取 county 為臺北市的圖形，輸出 `data/taipei.json`。若來源內容異動，程式會停止，不默默接受不同資料。

`2010` 表示五都升格後版本。上游 README 標示鄉鎮／縣市圖資為民國 101 年，村里圖資日期為 2012-11-13。`.3` 是上游稱為精度 0.001 的簡化版本，不是測量誤差保證，也不是「第 3 級行政區」。GeoJSON geometry 使用經緯度；properties 內另有歷史 TWD97 類型座標欄位，不可混用。

該資料授權尚待確認，因此不收錄於 Git；MIT 不涵蓋此第三方圖資。見 THIRD_PARTY_NOTICES.md。

## 改用官方現行里界的驗收條件

1. 保存原始來源、檔案版本、有效日期、授權與雜湊；不把下載日期當成有效日期。
2. 檢查 SHP 的 `.prj`，將正確來源座標系統轉成 WGS84，不直接假定所有 TWD97 都是同一 EPSG。
3. 保留行政區／里穩定識別碼，以「區＋里」顯示名稱，避免同名里混淆。
4. 逐筆比對官方名冊，檢查 12 區、456 里及各區數量，記錄新增、刪除、改名與換碼。
5. 檢查 Polygon／MultiPolygon、空圖形、自相交、重疊、縫隙及簡化前後的拓樸。
6. 建立共邊鄰接，分辨只有點接觸、河川隔開及橋梁連結，清楚標示檢查定義。
7. 人口資料須有共同統計月份及一致里代碼；區域議員人口計算另需釐清原住民人口處理。

目前的連通提示僅依舊圖資共用座標點判斷，包含點接觸，不能代表法定連通或合法劃分。
